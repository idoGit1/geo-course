# אטלס · קורס גאוגרפיה

אתר קורס גאוגרפיה חינמי בעברית, בנוי ב-React + TypeScript + MUI, מסודר RTL מלא, עם 6 יחידות לימוד ותוכן לדוגמה (סרטונים, קריאה, מטלות).

## הרצה מקומית

דורש Node.js 18 ומעלה.

```bash
npm install
npm run dev
```

האתר ייפתח בכתובת שתוצג בטרמינל (בדרך כלל `http://localhost:5173`).

בנייה לפרודקשן:

```bash
npm run build
npm run preview
```

## מבנה הפרויקט

```
src/
  theme.ts            עיצוב MUI: פלטת צבעים, טיפוגרפיה, כיוון RTL
  rtlCache.ts          מטמון emotion שהופך את ה-CSS של MUI ל-RTL
  types.ts              טיפוסי TypeScript לתוכן הקורס
  data/units.ts          תוכן 6 היחידות (כותרות, סרטונים, פסקאות, מטלות)
  components/            רכיבים לשימוש חוזר (ראו למטה)
  pages/
    Home.tsx              עמוד ראשי - היירו + רשת יחידות
    UnitPage.tsx           עמוד יחידה - טאבים לסרטונים / קריאה / מטלות
    NotFound.tsx           עמוד 404
```

### רכיבים לשימוש חוזר (components/)

| רכיב | תפקיד |
|---|---|
| `Navbar` | סרגל ניווט עליון + מגירה נפתחת מימין למובייל |
| `Footer` | פוטר קבוע |
| `HeroBanner` | באנר פתיחה, משמש גם בעמוד הראשי וגם בכל עמוד יחידה |
| `TopoPattern` | רקע דקורטיבי של קווי גובה (טופוגרפיה) - האלמנט החזותי החוזר של האתר |
| `CoordinateChip` | תגית קטנה בגופן מונוספייס בסגנון תווית מפה (מספר יחידה, קנה מידה) |
| `UnitCard` | כרטיס יחידה ברשת בעמוד הראשי |
| `SectionHeader` | כותרת אחידה לכל אחד מהאזורים (סרטונים/קריאה/מטלות) בעמוד יחידה |
| `VideoCard` | כרטיס סרטון + חלון נגן מוטמע (לשימוש עבור כל סרטון בכל יחידה) |
| `ParagraphBlock` | בלוק קריאה מתקפל עם מונחי מפתח (לשימוש עבור כל פסקה בכל יחידה) |
| `AssignmentCard` | כרטיס מטלה עם שאלות שהתשובה אליהן נחשפת בלחיצה |
| `TabPanel` | עוטף טאבים גנרי לשימוש חוזר |

## החלפת סרטונים אמיתיים

תוכן הסרטונים בקובץ `src/data/units.ts` הוא לדוגמה בלבד - שדה `youtubeId` נשאר ריק בכוונה כך שבמקום נגן מוטמע מוצגת הודעת placeholder ידידותית. כדי להטמיע סרטון אמיתי, מצאו את מזהה הסרטון ביוטיוב (החלק שאחרי `v=` בכתובת) והדביקו אותו בשדה המתאים, למשל:

```ts
{
  id: 'v1',
  title: 'מהי גאוגרפיה?',
  youtubeId: 'dQw4w9WgXcQ', // <- מזהה אמיתי מיוטיוב
  ...
}
```

## עריכת תוכן

כל תוכן הקורס (כותרות יחידות, פסקאות, שאלות מטלות) נמצא במקום אחד - `src/data/units.ts` - כך שאפשר לערוך, להוסיף או להסיר תוכן בלי לגעת ברכיבי העיצוב.

## RTL ועברית

- `index.html` מוגדר עם `lang="he" dir="rtl"`.
- `ThemeProvider` מקבל `direction: 'rtl'` בקובץ `theme.ts`.
- `CacheProvider` עם `stylis-plugin-rtl` הופך את כל ה-CSS שמייצר MUI ל-RTL אוטומטית.
- הגופנים הם Rubik (כותרות), Heebo (טקסט) ו-Space Mono (תוויות מספריות), נטענים מ-Google Fonts בקובץ `index.html`.

כל התוכן באתר חינמי ופתוח לעריכה חופשית.
